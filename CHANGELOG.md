## [0.1.0] - 2026-08-11

- Added local conversion, normalization, chunking, indexing, search, and bounded retrieval.
- Added standard-library readers for DOCX, XLSX, PPTX, EPUB, HTML, and text formats.
- Added optional routing for MarkItDown, Pandoc, Poppler, and Calibre.
- Added dependency-free smoke tests and a Python 3.9/3.11/3.13 CI matrix.
- Added Codex metadata, installation guidance, privacy safeguards, and an MIT license.
